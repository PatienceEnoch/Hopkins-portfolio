Projects I can explain from the inside out

Network Flight Recorder

Python · Linux · Docker · Terraform · AWS · S3 · CloudWatch · GitHub Actions

A local-first network troubleshooting and observability system built around one question: what changed?

It captures known-good network state, detects meaningful changes, correlates evidence into likely root causes, tracks incidents through recovery, and preserves diagnostic evidence locally even when cloud connectivity is unavailable.

  • Reproducible Docker failure injection
  • Evidence-backed diagnosis and incident lifecycle tracking
  • Terraform-managed S3 and CloudWatch operations layer
  • Deterministic redaction for sensitive network evidence
  • Approval-gated remediation, verification, and rollback
  • pytest, Ruff, dependency auditing, and Terraform validation in CI

Mini Internet

BGP · FRRouting · Docker Compose · Linux · IPv4 · Failover testing

Three routers, three private autonomous systems, and a link I can deliberately turn off.

I built the lab to watch BGP choose an alternate path during failure. I then compared the default 60/180-second BGP timers with 3/9-second timers and documented the difference between having a backup route and actually converging quickly enough to use it.

Shipment Tracker

Python · FastAPI · SQLAlchemy · SQLite · Email automation · GitHub Actions

A workflow application built around a real operational problem: determining whether a sales order received a shipping label and whether the carrier actually acquired the package within the expected time window.

The project includes persistent order state, overdue alerts, deduplication, API endpoints, a browser dashboard, and automated tests.
