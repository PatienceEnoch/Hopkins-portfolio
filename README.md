## Featured Projects

### [Network Flight Recorder](https://github.com/PatienceEnoch/network-flight-recorder)
A working, local-first Linux diagnostic MVP that captures known-good network state, detects high-signal changes during an outage, and generates an evidence-based incident report. It demonstrates Linux administration, TCP/IP troubleshooting, Python packaging, automated testing, secure subprocess handling, and GitHub Actions.

### [Tor Middle Relay Deployment](https://github.com/PatienceEnoch/TOR_Relay)
Deployed and documented a non-exit Tor middle relay in a Kali Linux virtual machine. The project demonstrates Linux service administration, TCP/IP networking, port configuration, traffic validation, log analysis, and repeatable troubleshooting.

### [Ubuntu Virtual Network Lab](https://github.com/PatienceEnoch/Ubuntu-virtual-network-lab)
Built a two-machine Ubuntu lab using static IP addressing, IP forwarding, nftables NAT, DNS, SSH, Apache, and tcpdump. Validated internal communication, routed internet access, name resolution, remote access, and web service availability.

### AWS VPC Networking Lab
Built a segmented AWS VPC using a `10.0.0.0/16` address space with public and private subnets, an internet gateway, NAT connectivity, routing tables, security controls, and EC2 resources.
